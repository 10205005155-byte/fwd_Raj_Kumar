A FEW FRIENDLY REMINDERS

Budgeting, without the stress.

How do I start a student budget?

Start with money coming in, then list essentials like rent, food, and transport. Set aside a little for flexible spending and adjust as you learn what works.

What if my spending changes every month?

That’s normal. Use a flexible estimate, check in weekly, and revise next month’s plan. A budget is a guide, not a test.

Is this dashboard connected to my bank?

No. These are sample figures for a student budget demo, not live financial data or financial advice.
